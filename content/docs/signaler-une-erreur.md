# Signaler une erreur

Une faute dans le texte, un code qui ne compile pas, un lien brisé, une figure illisible ou une explication peu claire ? Signalez-le ici. Chaque signalement aide à améliorer le cours pour tout le monde.

{{< boite type="remarque" titre="Votre signalement est anonyme" >}}
Le formulaire ne demande ni votre nom ni votre courriel, et aucune connexion n'est nécessaire.
{{< /boite >}}

## Comment faire ?

1. Indiquez la page concernée (module, section ou travail pratique). Si vous arrivez par le lien « Signaler une erreur dans cette page », elle est déjà indiquée.
2. Choisissez le type de problème.
3. Décrivez ce que vous avez remarqué : copiez le passage ou la ligne de code en cause et, si possible, ce qui serait correct.

Pour une question sur la matière ou sur votre travail, écrivez plutôt à votre personne tutrice.

{{< signalement >}}
